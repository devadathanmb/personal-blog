# devadathanmb.in

My personal blog — engineering notes, tools I use, things I think about.

Built with [Astro](https://astro.build) and deployed as a static site on Cloudflare Workers.

## Running locally

```bash
pnpm install
pnpm dev
```

Build:

```bash
pnpm build
pnpm preview
```
