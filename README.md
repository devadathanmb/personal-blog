# devadathanmb.in

My personal blog — engineering notes, tools I use, things I think about.

Built with [Astro](https://astro.build) and deployed on Cloudflare Workers.

## Stack

- **Framework:** Astro 5 (static output)
- **Styling:** UnoCSS
- **Search:** Pagefind
- **Comments:** Giscus
- **Fonts:** Inter + DM Mono

## Running locally

```bash
pnpm install
pnpm dev
```

Build:

```bash
pnpm build
pnpm preview
```
