The Diet Planner Application was developed as part of KTU's S6 mini project curriculum. It aimed to
address the challenge of diet planning using linear programming techniques. While effective in many
cases, we discovered limitations in its applicability under certain scenarios. Nonetheless, the
project was an insightful endeavor.

The application operates as a fully RESTful system with its own authentication mechanism
implemented.
