This is an API wrapper around ETLab portal which most of the engineering colleges in Kerala use to
track attendance, student information, exam details etc. The portal itself is a pain to work with
(no offense sorry). So I wrote an API wrapper that allows you to perform a login and grab all the
useful info so that, my boy, you can build all the cool stuff and be the next thing.

This is more like a next version of an old API wrapper that I wrote for my own collage portal
RITSoft (which is dead now since RIT switched to ETlab). This project has been forked and is being
utilized by individuals in other colleges to develop their own projects.
